# Cageforge

Cageforge is an independent, cross-platform Rust sandboxing library for
process-oriented harnesses, agents, build tools, and developer tools.

The project is being extracted and substantially refactored from relevant
open-source sandboxing code in [OpenAI Codex](https://github.com/openai/codex).
It is not affiliated with or endorsed by OpenAI. See
[`specs/0001-project-charter-and-licensing.md`](specs/0001-project-charter-and-licensing.md)
for the provenance, licensing, and architecture rules that govern this work.
